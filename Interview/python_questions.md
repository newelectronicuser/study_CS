# Python — Interview Questions

> Mid to Senior Level | Software Developer Role

---

## Language Fundamentals

1. What is Python's GIL (Global Interpreter Lock)? How does it affect multi-threaded programs?
2. What are Python's built-in data types? Which are mutable and which are immutable?
3. What is the difference between a list, a tuple, a set, and a dictionary?
4. What is list comprehension? How does it compare to `map()` and `filter()`?
5. What are `*args` and `**kwargs`? How are they used?
6. What is the difference between `is` and `==` in Python?
7. What is Python's memory management model? How does reference counting work?
8. What are Python decorators? Write a simple decorator example.
9. What is a generator in Python? How does `yield` differ from `return`?
10. What is the difference between `__iter__` and `__next__`?

---

## OOP in Python

11. What is the difference between `__str__` and `__repr__`?
12. What is multiple inheritance in Python and how does Python resolve method resolution order (MRO)?
13. What is the difference between a class method, a static method, and an instance method?
14. What are dunder (magic) methods? Name ten common ones.
15. What is a property decorator in Python? How is it different from a plain attribute?
16. What is the difference between composition and inheritance? When do you prefer each?
17. What is an abstract base class (ABC) in Python?
18. What is `__slots__` and how does it improve memory efficiency?

## Functional Programming

19. What is a lambda function in Python? When would you avoid using one?
20. What is `functools.partial()`? Give a use case.
21. What is `functools.lru_cache()` and when is it useful?
22. How does `map()`, `filter()`, and `reduce()` work in Python?
23. What is a closure in Python? Give an example.

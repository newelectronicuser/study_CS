# AWS & GCP — Interview Questions

> Mid to Senior Level | Software Developer Role

---

## Cloud Fundamentals

1. What is the difference between IaaS, PaaS, and SaaS? Give examples from AWS and GCP.
2. What is a region and an availability zone (AZ) in AWS? What is a zone in GCP?
3. What is the shared responsibility model in cloud security?
4. What is a VPC (Virtual Private Cloud)? What components make it up?
5. What is the difference between a public subnet and a private subnet?
6. What is a NAT Gateway and why is it used in a private subnet?
7. What is a security group vs a network ACL in AWS?
8. What is Cloud IAM and what are the key concepts (users, groups, roles, policies)?
9. What is the principle of least privilege in IAM?
10. What is a service account in GCP and how does it differ from an IAM user in AWS?

---

## Compute

11. What is EC2 in AWS? What is Compute Engine in GCP?
12. What are the EC2 instance purchasing options (On-Demand, Reserved, Spot, Savings Plans)?
13. What is an Auto Scaling Group (ASG) in AWS?
14. What is AWS Lambda? What are its limitations?
15. What is Google Cloud Functions vs Cloud Run?
16. What is a managed instance group (MIG) in GCP?
17. What is the difference between serverless and container-based compute?
18. What is AWS Fargate and how does it differ from ECS on EC2?

---

## Storage

19. What is Amazon S3? What are the different storage classes?
20. What is the difference between S3, EBS, and EFS?
21. What is Google Cloud Storage (GCS) and how do its storage classes compare to S3?
22. What is lifecycle management for object storage?
23. What is S3 versioning and how does it protect against accidental deletion?
24. What is a pre-signed URL in S3/GCS?

## Databases

25. What is Amazon RDS? What databases does it support?
26. What is Aurora and how does it differ from standard RDS?
27. What is DynamoDB? What are its key design considerations?
28. What is Cloud Spanner and what makes it unique?
29. What is Cloud Bigtable and what is it suited for?
30. What is ElastiCache in AWS? What is Memorystore in GCP?
31. How do you handle database connection pooling in a cloud-native application?

## Networking & CDN

32. What is an Application Load Balancer vs a Network Load Balancer in AWS?
33. What is Cloud Load Balancing in GCP and what are its types?
34. What is AWS CloudFront? What is Google Cloud CDN?
35. What is AWS Route 53 and what routing policies does it support?
36. What is Cloud DNS in GCP?
37. What is VPC Peering and how does it differ from Transit Gateway (AWS) or VPC Network Peering (GCP)?
38. What is AWS PrivateLink / GCP Private Service Connect?

46. What is Google Pub/Sub and how does it compare to SQS/SNS?
47. What is Amazon EventBridge?

# Java — Interview Questions

> Mid to Senior Level | Software Developer Role

---

## OOP & Language Fundamentals

1. What are the four pillars of OOP? Give Java examples for each.
2. What is the difference between an abstract class and an interface in Java?
3. When would you use an abstract class over an interface?
4. What is method overloading vs method overriding? What rules apply?
5. What is the difference between `==` and `.equals()` in Java?
6. What is the `hashCode()` contract? Why must you override `hashCode()` when you override `equals()`?
7. What is the difference between `final`, `finally`, and `finalize()`?
8. What is a static initializer block? When is it executed?
9. What is the difference between `static` and `instance` methods?
10. What are access modifiers in Java? Explain `public`, `protected`, `package-private`, and `private`.

---

## Collections Framework

11. What is the difference between `ArrayList` and `LinkedList`?
12. What is the difference between `HashMap`, `LinkedHashMap`, and `TreeMap`?
13. How does a `HashMap` work internally? What is hashing collision resolution?
14. What is the difference between `HashSet` and `TreeSet`?
15. What is a `ConcurrentHashMap` and how does it differ from `HashMap`?
16. What is fail-fast vs fail-safe iterators?
17. What is the difference between `Comparable` and `Comparator`?
18. When would you use a `PriorityQueue`?
19. What is the difference between `Stack` and `Deque` in Java?
20. What is `Collections.unmodifiableList()` vs `List.copyOf()`?

---

## Memory Management & JVM

21. What is the JVM architecture? Explain the major memory areas.
22. What is the difference between heap and stack memory in Java?
23. How does garbage collection work in Java? Explain the generational GC model.
24. What are the different GC algorithms available in the JVM (G1, ZGC, Shenandoah, etc.)?
25. What is a memory leak in Java? Give an example.
26. What is the `WeakReference`, `SoftReference`, and `PhantomReference`?
27. What is class loading? Explain parent delegation model.
28. How do you tune JVM heap size in a production environment?

---

## Exception Handling

29. What is the difference between checked and unchecked exceptions?
30. What is the exception hierarchy in Java?
31. What is the try-with-resources statement and how does it work?
32. What is the difference between `throw` and `throws`?
33. What is a multi-catch block (`catch (ExA | ExB e)`)?
34. When should you create a custom exception class?

## Design Patterns

35. What is the Singleton pattern? How do you make it thread-safe?
36. What is the Builder pattern? When is it preferred over constructors?
37. What is the Factory Method vs Abstract Factory pattern?
38. What is the Observer pattern? How is it implemented in Java?
39. What is the Strategy pattern? Give a use case.
40. What is the Decorator pattern? How does it differ from inheritance?
41. What is dependency injection and how does it relate to the IoC principle?

---

## Generics & Type System

42. What are Java generics and why are they used?
43. What is type erasure in Java generics?
44. What is the difference between `List<?>`, `List<? extends T>`, and `List<? super T>`?
45. What is a bounded type parameter?

## Advanced Java

46. What is reflection in Java? What are the risks of using it?
47. What is the difference between serialization and deserialization?
48. What is `transient` keyword used for?
49. What are annotations in Java? How do you create a custom annotation?
50. What is the difference between `String`, `StringBuilder`, and `StringBuffer`?
51. How does the `String` pool (intern pool) work?
52. What is the difference between an inner class, a static nested class, and an anonymous class?
